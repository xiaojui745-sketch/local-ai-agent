# 化学模拟原型：现场演示操作卡

按下面顺序操作，即可从 Windows 桌面打开演示。演示使用本机 Ollama（qwen3:8b）和 YOLO 模型；不需要 Codex 协助，也不需要联网下载模型。

## 开机后启动

1. 等 Windows 桌面完全显示。
2. 启动 Ollama：按 **Windows 键**，输入 `Ollama`，点击 Ollama 应用。若 Ollama 已在右下角托盘运行，不必重复启动。演示页里显示 Ollama 的 Apps 清单不是错误；将窗口最小化即可。
3. 打开文件资源管理器，在地址栏输入 `D:\YOLO\chemistry_sim\demo` 并按 **Enter**。
4. 双击 `start-demo.bat`。第一次启动 WSL/YOLO 可能要等一会儿。黑色终端出现 `Model ready` 或 `opening http://localhost:8765` 后，服务已就绪。**演示期间不要关闭这个终端窗口。**
5. 打开 Edge 或 Chrome，在地址栏输入 `http://localhost:8765/` 并按 **Enter**。地址必须以 `http://localhost:8765/` 开头；不要双击 `index.html`，也不要使用 `file:///...` 地址。

## 演示方程式和动画

1. 在页面向下找到 **“② 播放预设反应动画”** 下的 **“输入化学方程式”**。
2. 输入：`CuSO₄ + 2NaOH → Cu(OH)₂↓ + Na₂SO₄`
3. 点击 **“本地 AI 分析”**，等待页面显示 qwen3:8b 建议使用“硫酸铜 + 氢氧化钠（沉淀）”。
4. 点击 **“开始演示”**，等待浅蓝色沉淀动画播放完成。

也可用 `CH₃COOH + NaHCO₃ → CH₃COONa + H₂O + CO₂` 演示气泡场景。

## 展示 YOLO 器材识别（可选）

1. 回到页面顶部的 **“① 用训练好的 YOLO 识别器材”**，点击 **“选择文件”**。
2. 在文件选择窗口地址栏输入：`D:\YOLO\chemistry_sim\Chemical Apparatus Image Dataset\Chemical Apparatus Image Dataset\test\images`
3. 选择 `test_0040.jpg`，点击 **“打开”**，再点网页上的 **“识别图片”**。
4. 页面会显示检测框、器材类别和置信度。之前这张图片识别到一个 conical_beaker（锥形烧杯），置信度约 91.9%。

## 结束和常见问题

- 结束后切回启动服务的黑色终端，按 **Ctrl+C** 停止 YOLO 服务，然后可以关闭终端。
- 若页面显示 **Failed to fetch**：检查地址栏是不是 `http://localhost:8765/`，并确认黑色 YOLO 服务终端仍开着；不要从 `file:///` 打开页面。
- 若本地 AI 连接失败：确认 Ollama 已启动，再刷新演示页。不要关闭 Ollama 后台/托盘进程。
- 当前本地 AI 仅在气泡和沉淀两种预设中选择；其他反应暂不支持。动画是定性示意，不代表真实实验步骤或精确结果。
